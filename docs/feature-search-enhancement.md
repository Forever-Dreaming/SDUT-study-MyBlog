# 自主功能：搜索增强（Search Enhancement）

## 功能概述

在 Ghost 原生搜索的基础上，增加搜索历史记录、热门搜索推荐、搜索结果关键词高亮等功能，提升用户搜索体验。

## 用户故事

**作为一名博客读者，我希望：**
1. 能看到我之前搜索过的关键词，方便快速重新搜索
2. 能看到热门搜索词，了解大家都在搜什么
3. 搜索结果中能高亮显示关键词，快速定位匹配内容
4. 搜索无结果时能看到推荐内容，不空手而归

## 为什么在主题层实现？

| 方案 | 优点 | 缺点 |
|------|------|------|
| 修改 Ghost 核心 | 功能最强大 | 升级困难，维护成本高 |
| 独立搜索服务 | 可定制性强 | 部署复杂，需要额外维护 |
| **主题层前端增强** | 无需改核心，升级友好，零后端成本 | 受限于原生搜索能力 |

**选择理由：**
- 符合实验"不修改核心"的边界要求
- 纯前端实现，不增加服务端复杂度
- 利用 localStorage 存储历史，无需数据库
- 与原生搜索无缝集成，不破坏原有功能
- 升级 Ghost 版本时不受影响

## 功能清单

### 1. 搜索历史记录 ✅

**功能描述：** 自动记录用户的搜索关键词，最多保存 5 条，点击可快速重新搜索。

**数据来源：** 浏览器 localStorage（`sdut_search_history`）

**实现位置：**
- `assets/js/custom.js` - `initSearchHistory()` 函数
- `assets/css/custom.css` - `.sdut-search-history` 样式

**用户流程：**
1. 用户点击搜索按钮打开搜索框
2. 搜索框获得焦点且为空时，显示历史记录面板
3. 点击历史记录自动填入并搜索
4. 输入新内容并搜索后，自动添加到历史记录

**边界情况：**
- 历史记录为空时不显示面板
- 重复搜索同一关键词时，移到最前而非重复添加
- 超过 5 条时删除最旧的记录
- localStorage 不可用时静默降级

### 2. 搜索结果关键词高亮 ✅

**功能描述：** 在搜索结果中，将匹配的关键词用高亮样式标记出来。

**数据来源：** Ghost 原生搜索返回的结果数据

**实现位置：** `assets/js/custom.js` - 搜索结果 DOM 处理

### 3. 空搜索结果推荐 ✅

**功能描述：** 搜索无结果时，显示热门文章和标签推荐。

**数据来源：** Ghost Content API（`/ghost/api/content/posts/`）

### 4. 热门搜索推荐

**功能描述：** 在搜索框下方显示热门搜索关键词（基于文章标签权重）。

**数据来源：** Ghost Content API 获取标签列表，按文章数量排序

**实现方式：** 通过 `#get "tags"` 获取热门标签，作为推荐搜索词

## 数据来源说明

| 数据 | 来源 | 存储位置 | 隐私影响 |
|------|------|---------|---------|
| 搜索历史 | 用户输入的搜索词 | 浏览器 localStorage | 仅本地存储，不上传服务器 |
| 热门标签 | Ghost Content API | 实时获取 | 公开数据，无隐私问题 |
| 搜索结果 | Ghost 原生搜索 API | 实时获取 | 与原生搜索一致 |

## 失败状态处理

1. **localStorage 不可用**：搜索功能正常，历史记录功能静默禁用
2. **网络异常**：搜索功能按 Ghost 原生命名行为处理
3. **搜索结果为空**：显示友好提示和推荐内容
4. **关键词过长**：截断显示，完整内容在 tooltip 中
