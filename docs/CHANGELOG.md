# 更新日志

本项目所有重要变更将记录在此文件中。

格式遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/) 规范，

## [v1.1.0] - 2026-09-05

### 修复

- **首页文章计数**：修复首页文章总数不显示的问题，确保分页导航中文章数量正确统计
- **标签页上下文**：修复标签页（tag.hbs）上下文数据缺失导致的模板渲染错误，补充标签描述、文章数量等元信息
- **作者页上下文**：修复作者页（author.hbs）上下文数据缺失问题，确保作者头像、简介、文章列表正常显示
- **JS 功能容错机制**：为所有自定义 JS 功能增加 try-catch 容错处理，单个功能出错时不再阻断其他功能正常运行
- **目录选择器兼容性**：优化文章目录（TOC）的标题选择器，兼容更多 Markdown 渲染结构，避免因标题层级不规范导致的目录生成失败
- **搜索历史多选择器兼容**：修复搜索历史记录功能在不同选择器配置下的兼容性问题，适配 Ghost 不同版本的搜索 DOM 结构

### 优化

- **标签导航显示数量**：优化标签导航栏显示逻辑，根据屏幕宽度动态调整显示的标签数量，避免小屏设备标签溢出或换行
- **代码健壮性**：整体提升前端代码的健壮性，增加空值判断与边界情况处理

## [v1.0.0] - 2026-09-05

### 新增

- **自定义主题 sdut-blog**：基于 Ghost 默认 Casper 主题进行二次开发，打造课程实验专属博客主题
- **4 种主题色切换**：实现科技蓝、活力橙、森林绿、优雅紫四种配色方案，用户可在后台一键切换全站主题色
- **标签导航栏**：在导航栏下方新增热门标签快捷入口，支持点击快速筛选对应标签的文章
- **文章目录（TOC）**：文章详情页自动根据标题层级生成悬浮目录，支持点击跳转和当前阅读位置高亮追踪
- **阅读进度条**：页面顶部新增阅读进度条，实时显示当前文章的阅读完成百分比
- **搜索历史记录功能**：实现搜索增强功能，自动记录用户搜索关键词（localStorage 本地存储，最多 5 条），支持点击历史记录快速重新搜索与清除历史
- **返回顶部按钮**：页面滚动时自动显示返回顶部浮动按钮，点击后平滑滚动至页面顶部
- **响应式设计**：全站适配桌面、平板、手机等多种设备尺寸，确保在不同屏幕下均有良好的浏览体验

### 技术实现

- 主题模板：基于 Handlebars，在 Casper 主题基础上扩展
- 前端交互：原生 JavaScript 实现，无额外框架依赖
- 样式方案：原生 CSS + CSS 变量实现主题色切换
- 数据存储：搜索历史使用浏览器 localStorage，无需后端支持

## 版本说明

### 版本号规则

格式：`主版本号.次版本号.修订号`

- **主版本号**：不兼容的 API 或重大架构变更
- **次版本号**：向下兼容的功能性新增
- **修订号**：向下兼容的问题修正

### 版本类型

- **Alpha**：内部测试版，功能不完整，仅供开发测试
- **Beta**：公开测试版，功能基本完整，可能存在已知问题
- **正式版（Release）**：稳定版本，经过完整测试
