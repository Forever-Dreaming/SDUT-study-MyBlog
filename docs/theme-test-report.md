## 已知问题

### 1. CDN 资源加载失败

- **问题描述**：jsdelivr 在国内访问不稳定，导致 Ghost 官方的 `sodo-search`、`portal`、`comments-ui` 组件加载失败。
- **影响范围**：搜索功能、会员登录 / 注册、评论功能均无法正常使用。
- **问题性质**：这是网络问题，**不是主题 Bug**。主题代码本身已正确集成上述组件，组件资源由 Ghost 官方通过 jsdelivr CDN 提供。
- **解决方案**：可通过配置国内 CDN 镜像（如使用七牛云、又拍云等 jsdelivr 镜像源）或自建 CDN 加速来解决。

sdut-blog 主题的自有功能（标签导航、文章目录、阅读进度、返回顶部、搜索历史等）均已通过测试，页面渲染完整。受限于国内网络环境，Ghost 官方依赖 jsdelivr CDN 的三项功能（搜索、会员、评论）无法正常加载，建议部署时配置国内 CDN 镜像以获得完整体验。
