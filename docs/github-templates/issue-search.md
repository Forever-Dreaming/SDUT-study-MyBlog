# Issue 模板 - 搜索增强功能

## 标题
feat(search): 搜索历史记录增强

## 用户故事
作为博客的常客，我希望搜索时能看到我之前搜过的内容，这样可以快速找到之前感兴趣的文章，不用重新输入关键词。

## 验收条件

### 功能需求
- [ ] 搜索弹窗打开时，显示最近搜索记录
  - 最多显示 5 条历史记录
  - 按时间倒序排列（最新的在前面）
- [ ] 点击历史记录，直接执行对应搜索
- [ ] 每条历史记录旁有删除按钮，可单条删除
- [ ] 有"清除全部"按钮，一键清空所有历史
- [ ] 新搜索自动追加到历史记录顶部
- [ ] 搜索空内容不记录
- [ ] 重复搜索同一关键词时，将该词条移到顶部（去重）

### 兼容性
- [ ] 兼容 Ghost 原生 sodo-search 组件
- [ ] 兼容旧版 gh-search 组件结构
- [ ] 搜索组件加载失败不影响其他功能

### 数据与隐私
- [ ] 数据存储在浏览器 localStorage 中
- [ ] 不向服务器发送任何历史数据
- [ ] 清除浏览器数据后历史记录消失

### 非目标
- 不修改 Ghost 搜索后端逻辑
- 不替换 Ghost 原生搜索组件
- 不做搜索结果高亮（受限于原生搜索组件）
- 不做标签过滤等复杂搜索

## 技术方案
- 实现位置：主题层（assets/js/custom.js）
- 数据来源：localStorage（纯前端）
- 实现方式：监听搜索输入事件，拦截搜索行为，维护历史记录数组
- 兼容性：使用 MutationObserver 监听搜索弹窗 DOM 变化
