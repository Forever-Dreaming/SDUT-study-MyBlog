# Issue 模板 - 主题改造

## 标题
feat(theme): 自定义主题 sdut-blog 开发

## 用户故事
作为博客的读者和管理员，我希望有一个更美观、功能更丰富的博客主题，提供更好的阅读体验和个性化选项。

## 验收条件

### 基础结构
- [ ] 基于 Ghost 官方 Casper 主题开发，保留核心模板结构
- [ ] 主题名称：sdut-blog，版本 1.0.0
- [ ] 支持 Ghost 6.x 版本

### 功能需求
- [ ] 4 种主题色可切换（科技蓝/活力橙/森林绿/优雅紫）
  - 通过 Ghost 后台自定义配置项切换
  - 使用 CSS 变量实现主题色系统
- [ ] 首页标签导航栏
  - 显示热门标签（最多 8 个）
  - 点击可跳转至对应标签页
  - 使用 {{#get 'tags'}} 查询助手
- [ ] 文章目录（TOC）
  - 自动扫描文章 H2/H3 标题生成目录
  - 支持点击跳转至对应位置
  - 滚动时高亮当前阅读位置
  - 移动端自动隐藏
- [ ] 阅读进度条
  - 页面顶部显示阅读进度百分比
  - 实时更新
- [ ] 搜索历史记录
  - 保存最近 5 条搜索记录
  - 支持快速重新搜索
  - 支持单条删除和全部清除
  - 使用 localStorage 持久化
- [ ] 返回顶部按钮
  - 滚动超过 300px 后显示
  - 点击平滑返回顶部
- [ ] 文章卡片样式优化
  - 显示标签彩色点
  - 精选文章标记
  - 日期图标
- [ ] 响应式设计
  - 桌面端（> 992px）正常显示
  - 平板（768px - 992px）适配
  - 移动端（< 768px）适配

### 非目标
- 不修改 Ghost 核心代码
- 不替换 Casper 原生搜索组件
- 不改变后台管理功能

## 技术方案
- 模板层：Handlebars + Ghost 模板助手
- 样式层：CSS 变量 + 自定义 CSS（不修改原生 screen.css）
- 脚本层：原生 JavaScript（不依赖额外库）
- 数据来源：Ghost Content API + {{#get}} 查询助手
