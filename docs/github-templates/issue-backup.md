# Issue 模板 - 数据备份与恢复

## 标题
chore: 数据备份与恢复验证

## 用户故事
作为博客管理员，我需要定期备份博客内容数据，并能在需要时快速恢复，以防止数据丢失。

## 验收条件

### 备份内容
- [ ] 数据库文件（SQLite: ghost-local.db）
- [ ] 文章图片（content/images/）
- [ ] 自定义主题（content/themes/sdut-blog/）
- [ ] 配置文件（已脱敏，不包含密码）

### 备份方式
- [ ] 手动备份：可通过文件复制完成
- [ ] 后台导出：Ghost 管理后台的导出功能
- [ ] 备份文件命名：backup-YYYYMMDD-HHMMSS/

### 恢复验证
- [ ] 停止 Ghost 后替换数据库文件可正常启动
- [ ] 恢复后文章、标签、会员数据完整
- [ ] 恢复后主题正常工作
- [ ] 恢复后图片正常显示

### 备份清单
- [ ] 备份时间
- [ ] Ghost 版本
- [ ] 主题版本
- [ ] 包含内容说明
- [ ] 恢复步骤说明

## 非目标
- 不做自动化定时备份
- 不做增量备份
- 不备份运行日志
